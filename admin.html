Connect the editor

This is a one-time setup on each computer. A grown-up with the GitHub account needs to do it.

  1. Open GitHub's new token page (signed in as PatryckA).
  2. Token name: Sprinkle Studios editor. Expiration: up to 1 year.
  3. Repository access: Only select repositories and pick sprinkle-studios.
  4. Permissions: Contents set to Read and write. Nothing else.
  5. Click Generate token, copy it, and paste it below.

The token is saved only in this browser on this computer. Anyone using this computer's browser could edit the website, so keep it on a computer at home.
